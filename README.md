# 视频资源下载器

Chrome / Edge（Manifest V3）扩展。识别网页中的视频、音频和图片资源，预览后一键下载。不录屏、不重新编码、不上传任何数据，也不需要本地辅助程序。

![弹窗界面](docs/screenshot.png)

## 功能

- **识别**：列出页面中的媒体资源，卡片显示标题、封面、时长、分辨率和文件大小
- **预览**：点击封面即可预览（视频、音频播放，图片查看），下载前先确认内容
- **下载**：直接文件原样保存；HLS 可选清晰度并自动转封装为 MP4；最多 3 个并发，其余排队
- **站点适配**：抖音、B 站、小红书（含图文笔记多图下载），普通视频站通用识别
- **来源回退**：CDN 校验 Referer 时（如 B 站）自动改用网页来源抓取，不留失败记录
- **任务管理**：进度、取消、重试、打开文件、在文件夹中显示；可展开浏览器标签页面板

## 安装

1. 克隆本仓库，或下载最新 Release 后解压
2. Chrome 打开 `chrome://extensions`（Edge 打开 `edge://extensions`），启用「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本项目的 `extension` 目录
4. 刷新要下载的网页，播放媒体

## 使用

- 点击工具栏图标，在卡片上选择清晰度后点「下载」；点击封面可预览
- 也可以在网页视频上点右键，选「用视频资源下载器下载这个视频」
- 文件保存到浏览器下载目录的 `VideoDownloads/` 子目录，同名不覆盖
- 同一视频的多个下载任务互不阻塞，在弹窗或「展开下载面板」中分别管理

## 支持范围

| 资源 | 行为 |
| --- | --- |
| 直接视频 / 音频 / 图片文件 | 浏览器下载原文件，不转码 |
| HLS 点播（MPEG-TS / fMP4） | 读取并选择清晰度，下载全部片段后转封装 `.mp4`，只复制音画不重新编码 |
| DASH 清单 | 可识别，暂不支持下载 |
| 加密 HLS、DRM、直播 | 不支持，明确报错且不保存残缺文件 |

HLS 最多同时处理 3 个任务；TS 逐块写入浏览器私有磁盘，不受内存限制；fMP4 合并的输入上限为 256 MiB。

## 隐私与边界

- 不读取、复制或保存 Cookie / Authorization 等私有请求头
- HLS 与来源回退请求只临时补充 `Referer`（页面 origin，不含路径和参数），收到响应即清理
- 资源 URL、标题等仅保存在 `chrome.storage.session`，无遥测、无外部服务
- 不破解 DRM、不绕过登录或付费权限，请只下载你有权保存的内容
- 插件需要读取网页请求才能发现跨域 CDN 资源，浏览器会显示相应权限提示
- 不支持 Firefox；Chrome 内部页面与扩展页面不做资源识别

## 开发

```sh
npm ci
npx playwright install chromium
npm test    # 需要 FFmpeg / ffprobe
```

模块划分：`media-taxonomy.js` 媒体分类与命名中枢 · `catalog.js` 页面资源目录 · `background.js` 下载任务引擎 · `content.js` 站点适配器注册表 · `card-model.js` 弹窗视图模型 · `offscreen.js` + `hls.js` HLS 与来源抓取 · `source-fetch.js` Referer 来源租约。新增站点只需在适配器注册表加一条 `{name, extract, relay}`。
